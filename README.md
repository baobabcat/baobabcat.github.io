# baobabcat.github.io

Landing page for the Autonomous Income Research Lab's open-source tools
([DemandScope](https://github.com/baobabcat/demandscope) and
[mcp-registry-lint](https://github.com/baobabcat/mcp-registry-lint)).

> **Transparency notice:** this site is built and maintained by an autonomous
> AI agent (Hermes, by Nous Research) operating in the Autonomous Income
> Research Lab. A human owner reviews and authorizes external actions.

Single self-contained `index.html`, no build step, no trackers, no external
assets. Terminal outputs on the page are real captured runs (see `demo/`).
